# rootsh.com 多临时邮箱管理器

这是一个非官方的 Python 桌面客户端。它使用 rootsh.com 网页公开调用的接口，可以在一个窗口中同时管理多个临时邮箱。

列表中的每个邮箱都有独立的网络会话、Cookie、有效期、收件游标和邮件列表，邮箱之间不会共用状态。

## 运行

需要 Python 3.10 或更高版本。

```powershell
python -m pip install -r requirements.txt
python app.py
```

也可以双击 `start.vbs` 启动（不显示黑色命令行窗口）。`start.bat` 保留为兼容入口，会转交给无窗口启动器；若系统显示极短的闪现，请直接使用 `start.vbs`。

## 多邮箱使用方式

1. 点击“新建随机邮箱”，邮箱会立即添加到左侧列表；可以连续创建多个。
2. 在左侧选择邮箱，右侧可执行复制、续期、立即取件、下载和销毁。
3. 邮箱列表支持单选，也支持按住 `Ctrl` 或 `Shift` 多选；点击“删除选中邮箱”可一次销毁并删除一个或多个邮箱。
4. 程序不会常驻后台轮询邮箱；只有点击“立即取件”时手动刷新，或网站注册进入验证码等待阶段时每 10 秒检查一次。
5. 邮箱过期后会继续保留在列表中，选择它并点击“续期 10 分钟”即可恢复；点击“自动打开”“手动打开”或“后台注册”时，若邮箱已到期，程序会在后台自动续期，不阻塞浏览器窗口的打开。
6. 双击邮件读取正文，也可以保存原始 `.eml` 文件或下载整个邮箱。

## 浏览器会话策略：隔离或复用

顶部“浏览器”下拉框可以全局选择 Brave、Chrome、Donut 或 VirtualBrowser，选择会保存到 `settings.json`，所有邮箱的“自动打开”、“手动打开”和“后台注册”都会统一使用该浏览器。程序不会在所选浏览器缺失或 Donut API 不可用时静默回退；请安装/启动所选浏览器或在下拉框中切换。切换前需要先关闭本程序已打开的浏览器窗口，并等待正在执行的浏览器任务结束。

顶部“会话策略”下拉框可选择：

- **隔离会话**（默认）：每个邮箱都有自己的浏览器配置，不同邮箱不会复用 Cookie、登录状态、Local Storage 或缓存。
- **复用会话**：所有邮箱依次复用同一个浏览器数据目录、Donut 配置或 VirtualBrowser worker。每次登录或注册前，程序都会先在 [Creative Fabrica 账户页](https://www.creativefabrica.com/my-account/)确认当前账户已退出；若无法退出，则停止后续流程，避免串号。程序不会尝试从 Studio AI 页面退出，因为该页面没有退出入口。复用会话会保留浏览器的其他数据，不会清空整个浏览器配置。

复用会话一次只处理一个浏览器流程。可以连续点击多个账户的“后台注册”，程序会按点击顺序加入 FIFO 队列并逐个处理，不会并行复用同一会话。已有可见的复用会话窗口时，队列会等待窗口关闭。“手动打开”只负责打开复用会话窗口，不会代替你提交登录或退出操作。

Brave 与 Chrome 的隔离会话使用不同用户数据根目录；Donut 的复用会话使用一个专用 Wayfern 配置，VirtualBrowser 的复用会话固定使用同一个 worker。

### Donut Browser

1. 启动 Donut Browser，下载至少一个 Wayfern 版本，并接受 Wayfern 使用条款。
2. 在 Donut 的“设置 → 集成 → 本地 API”中启用 API；默认地址为 `http://127.0.0.1:10108`。
3. 在本程序顶部点击“Donut API”，填写本地 API 地址和 Token。Token 使用当前 Windows 用户的 DPAPI 加密后保存，也可以通过 `DONUT_API_URL` 和 `DONUT_API_KEY` 环境变量提供。
4. 在浏览器下拉框选择 Donut。隔离会话下，首次打开某个邮箱时，程序会为其创建专用 Wayfern 配置并保存 `profile_id`；以后始终使用同一配置和指纹。

程序通过 Donut REST API 启动配置，再让 Selenium 连接返回的 CDP 端口；兼容本地 0.28.1 的 `remote_debugging_port` 和新版 API 的 `cdp_port` 返回字段。后台注册会显示 Donut 浏览器窗口，并在任务结束后停止配置。若 Donut 显示配置仍在运行但原 CDP 端口不可用，请先在 Donut 中停止该配置。Donut 的 `/run`、`/kill` 和 CDP 自动化能力取决于当前 Donut 授权。

### VirtualBrowser worker 池

选择 `VirtualBrowser` 后，程序使用本机 `%LOCALAPPDATA%\VirtualBrowser\Workers` 下由 VirtualBrowser 创建的编号环境。点击顶部“VB worker 池”设置固定数量（默认 3）；程序只使用最小的 N 个环境，并按“最近最少使用”分配空闲 worker，绝不并发复用同一个 worker。后台任务结束后会归还 worker；需要人工完成 CAPTCHA 的 worker 会暂时保留给同一邮箱，以免丢失验证现场。

每次把空闲 worker 分配给新的邮箱前，程序会退出该 worker 中现有的 Creative Fabrica 会话并清除该站点 Cookie、Local Storage 和 Session Storage，然后才开始新的登录流程。指纹本身仍属于该 worker，因此这适用于你有权管理的账号和流程；不要将其视为规避网站规则或 CAPTCHA 的手段。VirtualBrowser 当前没有可依赖的公开“创建环境”接口，所以补充 worker 需要在 VirtualBrowser UI 中创建；本程序会自动发现新环境。已验证安装版内核可以由 Selenium 以 `--worker-id=<编号>` 启动。

- 每一行的“浏览器打开”列都直接提供“自动打开”和“手动打开”两个按钮，无需先在顶部切换模式。
- 每一行新增“后台注册”按钮：程序按照当前会话策略，在可见浏览器窗口中完成登录或注册、验证码取件、Studio 跳转与积分更新，完成后自动关闭后台驱动并持久化积分。
- 主界面提供独立的“后台注册状态”反馈条，持续显示正在处理的账户、排队数量以及成功、失败、待验证和结果未确认的统计；该反馈不会被下一项任务的普通状态信息覆盖。每个邮箱所在行也会保留“注册成功”“注册失败”或“注册成功但积分未读取”等明确结果。
- 一旦确认该邮箱已经登录或注册成功，“后台注册”按钮会从该行隐藏；已注册状态会持久化，程序重启后不会再次显示。旧数据中已有积分的邮箱会自动识别为已注册。
- 网站要求 CAPTCHA 时，后台任务会停止并把状态改为“需要手动验证”；复用会话的注册队列会暂停，避免下一账户覆盖验证现场。点击同一行“自动打开”即可在可见窗口中继续，完成验证并关闭窗口后队列自动恢复。
- 浏览器默认进入 Creative Fabrica 登录页，并使用当前临时邮箱同时作为账号和密码尝试登录。
- 登录失败时会直接转到注册页，使用当前临时邮箱作为账号和密码并自动提交注册，无需额外确认。
- 注册后程序会继续监听该行临时邮箱，识别 Creative Fabrica 邮件主题或正文中的验证码并自动填写。
- 登录或注册成功后会进入 Studio AI 读取 Coins 余额，并更新邮箱列表中的“积分”列。新注册账号先按 5000 积分显示，读取到网站实际余额后自动覆盖。
- 如果 Studio 子域没有自动继承主站会话，程序会打开 Studio 登录弹窗、切换到登录模式，并使用同一邮箱和密码完成登录后再读取任务栏余额。
- 若首次打开登录页或后续步骤显示 Cloudflare/CAPTCHA 人机验证，程序会保持窗口并等待最多 10 分钟；在对应的浏览器窗口中手动完成后，登录/注册流程会自动继续，不会再将缺少登录表单误报为“浏览器失败”。后台任务检测到验证时会停止并提示点击“自动打开”继续。
- 打开时会自动把该行的邮箱地址复制到剪贴板。
- 隔离会话下，再次打开同一个邮箱会继续使用它原来的专用浏览器数据。
- Chrome 配置保存在 `%LOCALAPPDATA%\TemporaryEmailPickup\browser_profiles`，Brave 配置保存在 `%LOCALAPPDATA%\TemporaryEmailPickup\browser_profiles_brave`；Donut 配置由 `%LOCALAPPDATA%\DonutBrowser` 管理，VirtualBrowser 配置由 `%LOCALAPPDATA%\VirtualBrowser\Workers` 管理。销毁邮箱时不会删除对应 Donut 或 VirtualBrowser 指纹配置，也不会强制关闭已经打开的浏览器窗口。

浏览器控制使用 Selenium。首次运行前请执行 `python -m pip install -r requirements.txt`。如果某个邮箱的浏览器窗口仍在运行，程序会通过已保存的调试端口重新连接；再次点击该行“自动打开”会继续使用现有窗口并重新进入 Studio 刷新积分。Donut 的 CDP 地址与 `profile_id` 会随邮箱数据一起持久化，以便程序重启后继续连接。

## 浏览器窗口跟踪

“自动打开”和“手动打开”的窗口会被程序持续观察（每 3 秒只读检查一次，不会驱动或干扰窗口操作）：

- 检测主站登录状态：识别到退出链接时自动把该邮箱标记为已注册并显示“网站已登录”；
- 停在 Studio AI 页面时读取积分并更新“积分”列；
- 窗口被关闭后自动把状态改为“浏览器已关闭”，释放对应的 VirtualBrowser worker。

手动打开的 Brave/Chrome 窗口通过 `--remote-debugging-port=0` 暴露本机调试端口（仅绑定 127.0.0.1），程序据此附加只读会话；VirtualBrowser 的手动窗口不参与跟踪。

关闭程序只会关闭本机网络会话，不会额外调用销毁接口；临时邮箱仍会按网站规则自然到期。

## 界面状态

邮箱列表与详情之间、收件箱与邮件预览之间的两个分割位置会自动保存。再次启动程序时，会根据当前窗口大小按比例恢复上次的位置。设置文件位于 `%LOCALAPPDATA%\TemporaryEmailPickup\settings.json`。

## 邮箱数据持久化

创建的邮箱会自动保存到 `%LOCALAPPDATA%\TemporaryEmailPickup\mailboxes.json`。程序下次启动时会恢复：

- 邮箱地址、域名、对应的隔离会话浏览器 key，以及 Donut `profile_id`/CDP 地址；
- Creative Fabrica/Studio AI 积分余额；
- 邮箱剩余有效期以及是否已经到期；
- rootsh 会话 Cookie、取件游标和已显示的邮件列表；
- 邮件的发件人、主题、大小和收件时间。

创建、续期、取件、删除邮件、删除邮箱和正常退出后都会立即更新文件。邮件正文仍按需从 rootsh 读取，不会长期复制到本地。已经到期的邮箱也会保留在列表中，可以尝试点击“续期 10 分钟”。

## Outlook 邮箱导入

点击顶部“导入 Outlook”，支持一次粘贴多行账号：

```text
邮箱----密码----OAuth客户端ID----刷新令牌
```

- 导入时只验证邮箱访问权限，不读取邮件列表；重复邮箱自动跳过。
- 优先通过 Microsoft Graph `Mail.Read` 读取收件箱；令牌权限不兼容时自动回退到 OAuth2 IMAP。
- Outlook 邮箱在有效期列显示“长期”，与 rootsh 临时邮箱共用收件列表、验证码识别和浏览器登录/注册功能。
- Outlook 密码及刷新令牌不会明文保存；它们通过当前 Windows 用户的 DPAPI 加密后写入 `mailboxes.json`，复制到其他 Windows 用户后无法解密。
- Outlook 导入当前按只读收件权限处理，“删除邮箱”只从本程序列表移除，不会删除 Microsoft 账号或远程邮件。

邮箱、邮件和会话均由 rootsh.com 管理。临时邮箱不适合接收密码、财务、身份信息等敏感内容；站点接口变化时客户端也可能需要随之更新。
